# Clank

A tmux-based development workflow that integrates Claude, Linear, GitHub, and fzf into five focused windows (plus a plain playground shell):

- **Ideate** — Capture new ideas and link them to Linear issues
- **Plan** — Pick Linear tickets, brainstorm, write implementation plans
- **Execute** — Pick plans, execute them task-by-task
- **Verify** — Live dashboard of your own open PRs with CI status, assign reviewers, finalize PRs
- **Review** — Live dashboard of open PRs assigned to you for review; select one to run a verified, terse review that ends in a pending GitHub review you submit yourself

## Prerequisites

All of these must be installed:

- [tmux](https://github.com/tmux/tmux)
- [fzf](https://github.com/junegunn/fzf)
- [gh](https://cli.github.com/) (GitHub CLI)
- [claude](https://docs.anthropic.com/en/docs/claude-code) (Claude CLI)
- [bat](https://github.com/sharkdp/bat)
- [jq](https://jqlang.github.io/jq/)
- [bk](https://github.com/buildkite/cli) (Buildkite CLI)
- [superpowers](https://github.com/anthropics/claude-code-plugins) Claude plugin: `claude plugins add superpowers`

## Install

```bash
./install.sh
```

The installer will:

1. Check dependencies
2. Generate `~/.clankrc` (project directory, session name, paths)
3. Symlink scripts to your PATH
4. Install Claude skills

## Configuration

### ~/.clankrc

Generated by the installer. Edit to change:

```bash
CLANK_WORK_DIR="$HOME/dev/hox"    # Your project directory
CLANK_SESSION="clank"              # tmux session name
CLANK_PLANS_DIR="$HOME/.claude/plans"
CLANK_CLAUDE_CMD="claude --permission-mode auto"  # How Claude is launched in every pane
CLANK_GH_REPO="hoxhunt/hox"        # Repo the review window lists PRs from
```

### LINEAR_API_KEY

Add to your shell profile (`.zshrc` / `.bashrc`):

```bash
export LINEAR_API_KEY="lin_api_..."
```

## Usage

```bash
clank
```

This starts a tmux session with 5 windows and a playground shell. Each window has an fzf picker on the left and Claude on the right. Select items from the picker to launch Claude sessions with the appropriate context.

## Uninstall

```bash
cd ~/dev/clank
./uninstall.sh
```
